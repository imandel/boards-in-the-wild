# Construction pipeline (coming)

The corpus construction code will land here before the SCF '26 proceedings
(December 2026): source catalog (`catalog/`), CAD normalization to KiCad
(`normalization/`), registration rendering (`render/`), photo–CAD matching and
acceptance (`matching/`), and CAD-to-photo projection (`projection/`). Until then the
dataset's `manifest.json` and per-table provenance columns record which pipeline stage
and receipt produced every released row.
